The old way

Automation shouldn't require an automation engineer.

Most end-to-end tooling assumes you already write code, hand-craft selectors, and have hours free to babysit a flaky suite after every release. That's a high bar for the person who actually knows the app best — the QA who uses it every day. Podium Studio starts from the opposite assumption: testing should be something you can hand to anyone on the team, this afternoon.

  • A script for every scenario

    Every new flow means someone who can code has to write it first.

  • Breaks on a rename

    One class name changes and the whole regression pack turns red for the wrong reason.

  • One person can fix it

    The suite only makes sense to the engineer who wrote it — everyone else waits.

  • Evidence you have to hunt for

    A failure is a red dot in a log, not something you can actually see happen.

How it works

Three steps. The engine does the rest.

No project setup, no framework choice, no boilerplate. This is the whole workflow.

01

Author

Describe the flow the way you'd explain it to a teammate — tap, type, check. No selectors to hand-write, no script to debug.

02

Run

A real engine drives a real device or browser — deterministic, step by step, the same way every single time it runs.

03

Evidence

Every step comes back with a screenshot, a full trace, and video — a failure is something you can watch, not guess at.

Under the hood

Built like a real testing engine, framed like a checklist.

Mobile and web, one flow

Target iOS, Android, and the web from the same authoring surface — build the flow once, run it where your users actually are.

Frame-aware web testing

Works across iframes, auto-dismisses cookie and consent overlays, and waits intelligently for elements instead of guessing at a delay.

Evidence built in

Per-step screenshots, a full trace, and video of every run — captured automatically, win or lose.

Self-healing selectors

When your UI shifts, Podium looks for what moved instead of failing the whole run over a rename.

AI assist for authoring

Describe a flow in plain language and get a draft you review — the assist stops there; every run itself stays deterministic.

Bilingual by design

The full UI works in English and Vietnamese, so the whole team authors and reads runs in the language they think in.

Questions

Before you download

Do I need to know how to code?

No. Flows are authored as plain steps — tap, type, check. Selectors and scripting live inside the engine, never on your screen.

What can Podium Studio test?

Deterministic end-to-end flows on mobile (iOS and Android) and the web, from the same desktop app.

What happens when my UI changes?

Self-healing selectors look for what moved instead of failing outright, and every run still leaves a screenshot, trace, and video so you can see exactly what happened.

Is there AI in the run path?

AI can help you draft a flow from a plain-language description, but every run itself is deterministic — no model guessing mid-run.

What does the free trial include?

Full access to author and run flows today, on macOS. Paid plans are coming later — we'll share pricing when it's ready.

Which languages does it support?

English and Vietnamese, end to end — the interface and the run output both.
